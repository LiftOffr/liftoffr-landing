Built on public data, so you can run it yourself.

The Score is built from CBBI's public daily data, weighted by numbers I publish on every indicator page. Pick any date on the receipts page, pull the same free source, run the same weights. You’ll get my number — with one rule that matters: divide by the weight you actually used, not by 1.00. On days when CBBI published no reading for one of the nine, that component is left out and the divisor drops to match. It affects a few hundred of the historical dates, so a recompute that divides by 1.00 regardless will disagree with me and will be wrong. The worked arithmetic is on /score.

That's the whole method, published. Most people in this category hand you a chart and a subscription. This hands you the formula.
