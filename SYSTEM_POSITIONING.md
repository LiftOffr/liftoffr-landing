so "the Score" is no longer what this product sells — anyone can have that without paying.

is why, and when I'll sell", of which the exit method IS the "when I'll sell". See the
matching note on `/plan`. If that decision is ever revisited, `/plan`, `/system` and the Whop
listing move in one sitting or it just relocates the contradiction.

The "signals feed" this note used to cite as part of the value no longer exists.

copy.
