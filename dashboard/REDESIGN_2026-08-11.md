# Private Terminal — redesign, 2026-08-11

Design-layer rebuild of `dashboard/index.html`. The data engine is untouched:
all 107 element ids the JS reads and all 165 classes it emits or queries were
preserved and verified programmatically before the file was written out.

## What the research said, and what it changed here

| Principle | Source | What it changed |
|---|---|---|
| **Deference** — UI serves content, never competes | Apple HIG core principles | Removed emoji section headers, the HUD scanline overlay, the animated sweep on the stance cell, and the cyan "JARVIS" accent that was fighting the brand red |
| **One clear focal point; biggest number = most important** | Fintech dashboard practice | Position promoted from section 11 to a hero panel. Nothing else on the page is set larger |
| **Restrained type scale** | Apple's Dynamic Type ladder (34/28/22/17/16/13/11) | 24 distinct font sizes collapsed to 8 steps |
| **True greys, layered elevation, never pure black** | Dark-mode dashboard practice | `#070707`/`#04060a` → `#0B0B0D` base with `#131316` / `#1A1A1F` / `#232329` surfaces |
| **Green and red are signals, not branding** | Dark-mode + fintech practice | Green was on gains, buttons, live dots, progress fills and most numbers. Now: `--pos`/`--neg` are used **only** where money moved. The primary button is brand red |
| **2–3 accents maximum in charts** | Dark-mode practice | Palette cut to brand red + Apple's systemGreen/Red/Orange/Blue |
| **Editorial restraint, one CTA colour, dark canvas** | Mercury design system | Section headers are plain type; the only saturated colour in the chrome is the active nav indicator |
| **≥44pt touch targets, safe-area insets** | Apple HIG | Every control now ≥44px on mobile; `env(safe-area-inset-*)` honoured |

## New panels (real data only)

**Hero — Bitcoin Position.** Market value, unrealized P/L, average cost basis,
realized P/L, dry powder, next DCA buy.

The cost basis is the substantive fix. The existing `planAvgCostBasis()` filters
to `PLAN.phases[0].start`, which answers "how much of *this plan* have I
deployed" — a different question. Against the coin actually held it understates
badly, which is why the analyst kept reporting *"a cost basis for the existing
coin isn't in today's report, so I can't state unrealized P/L."* The hero
computes lifetime average cost across every synced fill, reducing the pool at
the running average on sells. The ladder's phase-scoped figure is untouched
where it belongs.

**Value Over Time.** Market value of the coin held on each day against cash in
by that day, rebuilt from the fills and the daily close. Day-over-day swing is
measured on `(value − money in)` so a deposit isn't reported as a good day —
that mistake showed a "+$27,951 best day" in the first draft.

**Next DCA buy** is *inferred* from the median gap and median size of the last
45 days of fills, and says so on the card. The recurring buy lives in Coinbase,
not in this repo, so there is no schedule to read and none is invented.

## Honesty rules in the new code

- Anything not derivable from a real fill or a live balance renders an em dash.
- When the wallet holds more BTC than the ledger explains, the hero says so and
  states which quantity the P/L is against.
- Coinbase down → balances show "—" and the panel says so; P/L survives because
  it comes from the local ledger and the price feed, and the copy says that too.
- Price feed down → value falls back to a BTC quantity, P/L goes to "—".

## Verified

At 375px and 1440px against live Coinbase / CBBI / price data:

- Auth gate: 401 unauthenticated, 401 wrong password, 200 correct — unchanged.
- All 17 sections render; nav scroll-spy and section collapse both work.

## Flagged, not changed

1. **`dashboard/apply-mobile-fixes.mjs`** — an untracked patch script from a
   concurrent session, still uncommitted. It found several real problems and its
   fixes are now folded in here (grid min-width blowout, 44px targets, ledger
   cap, safe-area insets, action-bar orphan cell). **Its string anchors no
   longer exist**, so running it now would report SKIPPED for everything.
   Two of its items were *not* carried over and are still open: persisting
   section-collapse state across reloads, and keyboard a11y on section headers.
2. **Ledger state drift.** A fresh `/api/coinbase-sync` returns 208 fills with
   19 sells; the browser's stored ledger has 192 fills with 3 sells, so realized
   P/L reads +$2,110 rather than roughly +$7,955. The hero reports the ledger
   faithfully — hit "Sync Coinbase" to reconcile.
3. **Four stale dashboard copies** are still served (auth-gated) at
   `/dashboard/index-original.html`, `index-v2.html`, and two `.backup-*` files.
   They contain real balances and loan figures. Recoverable from git; deleting
   them is a judgement call so it was left alone.
4. **`--force-device-scale-factor` / narrow-window headless Chrome** stopped
   producing screenshots on this machine partway through. Mobile was verified
   through the live browser pane instead, with measurements rather than eyeball.
